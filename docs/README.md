# Creatye Studio Docs

This folder contains durable project knowledge for Creatye Studio.

Native Jaxx files remain the source of truth for project state, plan, progress, decisions, and verification:

- State: `.agent/STATE.md`
- Plan: `.agent/PLAN.md`
- Progress: `.agent/PROGRESS.md`
- Decisions: `.agent/DECISIONS.md`
- Verification: `.agent/VERIFICATION.md`

Start with `docs/project/CONTEXT_INDEX.md` to find only the context needed for a task.
