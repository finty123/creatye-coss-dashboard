# Core Journeys

These are macro product journeys, not UI flows.

## Journey 01 - Connect Social Account / Page

START: workspace needs a social destination.

1. Select platform/account connection intent.
2. Connect or refresh external account.
3. Discover available pages.
4. Select pages for the workspace.
5. Confirm operational availability.

END: pages are available for publishing, automation, and analytics.

## Journey 02 - Create Content

START: user needs publishable material.

1. Create content draft.
2. Attach or create media/assets.
3. Produce variants when needed.
4. Prepare output for one or more targets.
5. Mark content ready for publishing or reuse.

END: content is ready for publishing, automation, or template reuse.

## Journey 03 - Create Video

START: user needs video content.

1. Start video project.
2. Import, generate, or reuse media/assets.
3. Compose or transform video.
4. Render output.
5. Attach output to content.

END: video output becomes reusable content material.

## Journey 04 - Create Image

START: user needs image content.

1. Start image project.
2. Import, generate, or reuse media/assets.
3. Compose or transform image.
4. Render/export output.
5. Attach output to content.

END: image output becomes reusable content material.

## Journey 05 - Create Automation

START: user needs operational behavior.

1. Define trigger.
2. Build flow with conditions, actions, waits, and branches.
3. Connect relevant pages/content/messages.
4. Review execution intent.
5. Activate automation.

END: automation can react to events and produce execution results.

## Journey 06 - Publish / Schedule Content

START: content is ready to distribute.

1. Select content and variants.
2. Select targets/pages/platforms.
3. Choose publish now or schedule.
4. Queue or execute publish attempts.
5. Track success, failure, retry, or cancellation.

END: content is published, failed, canceled, or waiting for retry.

## Journey 07 - Monitor Performance

START: activity has occurred in pages, publications, automations, or interactions.

1. Collect raw platform metrics and product activity.
2. Normalize metrics into comparable product signals.
3. Review performance by page, content, publication, automation, and operation.
4. Detect changes, failures, or opportunities.

END: user understands current operational performance.

## Journey 08 - Analyze and Optimize

START: performance data exists.

1. Compare results against goals or prior performance.
2. Identify bottlenecks, winning content, weak targets, or automation issues.
3. Generate recommendations or optimization ideas.
4. Apply changes to content, publishing, automation, or targeting.

END: the next loop starts with better context.

## Journey 09 - Reuse Template

START: user wants to repeat a proven structure.

1. Select template.
2. Adapt it to workspace/page/content context.
3. Customize required fields or assets.
4. Produce content, project, or automation from the template.

END: reusable structure becomes active work.

## Journey 10 - Manage Multiple Pages

START: workspace operates more than one page.

1. Review page inventory and status.
2. Group or select pages by operational need.
3. Apply content, publishing, automation, or analytics tasks across selected pages.
4. Monitor differences by platform/page.

END: multi-page operation remains coordinated.
