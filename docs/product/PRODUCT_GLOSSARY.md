# Product Glossary

Official terms for M001 product architecture.

| Term | Official meaning |
| --- | --- |
| Workspace | The operating container for a team's Creatye Studio activity. |
| User | A human identity that can participate in workspaces. |
| Member | A user's participation inside a workspace. |
| Account | An external platform account or internal user account depending on context; prefer `Social Connection` for external platform authorization. |
| Connection | Authorization/link between a workspace and an external platform account. |
| Social Connection | The official term for an external platform connection. |
| Page | A social page, profile, or channel that the workspace can manage through a social connection. |
| Target | A selected destination for publishing or distribution, usually derived from a Page. |
| Media | Source material imported, captured, generated, or otherwise available for use. |
| Asset | A usable media item or derivative in the content inventory. |
| Project | A creative working container used to produce or transform video/image outputs. |
| Content | A publishable product concept that can use media, assets, variants, and outputs. |
| Variant | A version of content adapted for a target, platform, format, audience, or experiment. |
| Output | A finalized file or artifact prepared from content or creative production. |
| Template | A reusable structure for content, creative production, or automation. |
| Publication | The plan to publish content to one or more targets. |
| Post | The external platform representation of published content; use `Published Content` inside Creatye Studio unless referring to platform-native wording. |
| Published Content | Content that has been successfully delivered to an external target. |
| Publish Attempt | One attempt to deliver a publication to a target. |
| Automation | Operational rule set that reacts to events and runs flows. |
| Flow | The internal logic path of an automation. |
| Journey | A macro product/user journey, not automation logic. |
| Trigger | Event matcher that starts or routes automation. |
| Condition | A decision rule inside a flow. |
| Action | A flow step that performs work. |
| Wait | A flow step that pauses execution until time or condition criteria are met. |
| Branch | A split in a flow based on a condition or event. |
| Execution | One runtime occurrence of an automation flow. |
| Interaction | Audience, platform, or system event observed by the product. |
| Metric | Measured signal about page, content, publication, automation, interaction, performance, or operational activity. |
| Raw Platform Metric | Metric as received or understood from an external platform. |
| Normalized Metric | Metric translated into product-level meaning for comparison and analysis. |
| Insight | Interpretation derived from metrics and context. |
| Recommendation | Suggested action generated from analytics, intelligence, or product context. |
| Notification | User-facing signal about an operational event, approval, warning, or status. |

## Reserved distinctions

- Flow is automation logic. Journey is a product/user path.
- Content is publishable. Media and Assets are materials.
- Publication is the plan. Published Content is the result.
- Social Connection links an external platform. Page is what the workspace operates through that connection.
