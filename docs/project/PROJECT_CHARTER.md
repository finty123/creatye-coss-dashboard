# Project Charter

## Project

- Operational name: Creatye Studio
- Name status: provisional and may change later
- Repository: `creatye-v2`

## Product

Creatye Studio is an integrated platform for content and social operations, with modules for:

- Automation
- Video Studio
- Image Studio
- Publishing
- Page management
- Templates
- Analytics
- Artificial intelligence
- Optimization

## Conceptual cycle

CREATE -> AUTOMATE -> PUBLISH / DISTRIBUTE -> ANALYZE -> OPTIMIZE -> REPEAT

## Experiences

Web Desktop is productivity-first.

Mobile WebApp is app-first and touch-first.

Mobile must not be treated as simple responsive Desktop.

Backend and domain logic are shared.

## Technical stack

No technical stack is defined in this milestone.

The technical stack will be decided in M005.
