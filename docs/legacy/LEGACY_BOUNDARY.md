# Legacy Boundary

The old Creatye system is a source of product, domain, integration, and experience knowledge.

It is not the architecture base for this new project.

## Reuse classification

Any future reuse must be classified before action:

- REUSE
- ADAPT
- REWRITE
- DISCARD

## Never copy automatically

Do not automatically copy from the legacy system:

- Architecture
- Database design
- Schemas
- Services
- Components
- Workflow engine
- Infrastructure

First analyze. Then decide.
