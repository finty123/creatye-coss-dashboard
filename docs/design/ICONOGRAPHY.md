# Iconography

## Style

Use one icon family in future implementation unless a deliberate exception is documented.

The default icon style should be:

- Simple.
- Outlined.
- Consistent stroke.
- High optical clarity at small sizes.
- Compatible with dense UI.

## Sizes

Use stable size roles:

- Small: dense tables, metadata, compact controls.
- Standard: buttons, navigation, menus.
- Large: rare empty states or high-emphasis actions.

## Usage rules

- Icon-only actions require accessible labels and tooltips.
- Icons must align optically with text and control geometry.
- Status icons must match status semantics and not rely on color alone.
- Filled icons are reserved for selected, active, or high-emphasis states when the system defines them.
- Do not mix arbitrary icon styles across domains.
