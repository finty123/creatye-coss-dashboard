# AI Experience

AI is a transversal assistance layer, not a separate decorative product.

## AI capability modes

- Assist.
- Generate.
- Analyze.
- Recommend.
- Optimize.
- Explain.
- Classify.
- Summarize.
- Transform.

## State language

Users should understand when AI is:

- Suggesting.
- Generating.
- Changing.
- Analyzing.
- Waiting for input.
- Applying changes.
- Unsure.

## Design rules

- Do not default AI to purple buttons with sparkle icons.
- AI actions must explain scope before making meaningful changes.
- Applied AI changes should be reviewable and undoable.
- Confidence and uncertainty should be communicated when relevant.
- Recommendations should show rationale or evidence when possible.
- AI should respect domain context: content, automation, publishing, analytics, and optimization.

## User control

The user remains in control. AI should accelerate, suggest, explain, or transform, but not silently mutate important work.
