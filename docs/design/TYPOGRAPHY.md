# Typography

M002 defines typography roles and selection criteria, not a final font dependency.

## Selection criteria

The type system must support:

- High legibility in dense interfaces.
- Clear numeric reading.
- Tables, analytics, labels, controls, and editors.
- Multiple viewport sizes.
- Good rendering on common operating systems.
- Distinct but compatible monospace use.

## Roles

| Role | Purpose |
| --- | --- |
| Display | Rare product-level emphasis, not dashboard decoration. |
| Heading | Section and page hierarchy. |
| Body | Primary reading and operational content. |
| Label | Controls, forms, filters, table headers, metadata. |
| Caption | Supporting details, helper text, timestamps. |
| Numeric | Metrics, counts, table numbers, analytics values. |
| Monospace | IDs, code-like values, technical logs, compact tabular references. |

## Weight

Use a restrained weight range:

- Regular for body.
- Medium for labels and controls.
- Semibold for hierarchy.
- Bold only for strong emphasis.

Avoid using weight as the only hierarchy signal.

## Line height

- Dense labels and controls use tighter line-height.
- Body text uses comfortable line-height.
- Tables use predictable vertical rhythm.
- Mobile uses touch-friendly line-height without inflating density unnecessarily.

## Letter spacing

Default letter spacing should remain neutral. Use adjusted letter spacing only for specific small-label or uppercase cases when legibility improves.
