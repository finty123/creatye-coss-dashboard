# Visual Language

## Visual tone

Creatye Studio should be restrained, crisp, and operational. The visual system should feel like a serious workspace for teams that produce, publish, automate, and analyze work daily.

## Hierarchy

Hierarchy should be created through:

- Type role and weight.
- Spatial grouping.
- Alignment and grid.
- Surface contrast.
- Border and divider use.
- State and status language.

Avoid relying on oversized typography, bright color, or decorative elevation for hierarchy.

## Surfaces

Use surfaces to separate meaning:

- Canvas: application background.
- Surface: primary work area.
- Subtle surface: panels, sidebars, grouped regions.
- Raised surface: popovers, menus, floating controls.
- Overlay surface: modal and blocking contexts.

Do not put every section in a card. Cards are appropriate when grouping, interaction, or separation is materially useful.

## Rhythm

The interface should have a steady rhythm: compact toolbars, readable content regions, clear dividers, and consistent control alignment.

Operational screens should prioritize scanning and repeated action over marketing-style presentation.
