# Control Finishing

Reference quality: Vercel Geist.

Use this reference for typography discipline, controls, buttons, inputs, tabs, dropdowns, spacing, and component finishing.

## Typography

Direction:

- Crisp hierarchy.
- Strong label clarity.
- Controlled weight usage.
- Legible body text.
- Reliable numeric/data styles.

Avoid:

- Trend-driven type choices.
- Oversized display type inside operational surfaces.
- Excessive weight contrast.

## Buttons

Direction:

- Precise sizing.
- Clear primary/secondary hierarchy.
- Controlled radius.
- Strong hover/focus/active states.
- Brand green used deliberately.

## Inputs

Direction:

- Quiet surfaces.
- Clear borders/focus.
- Good label/help/error behavior.
- No unnecessary visual chrome.

## Tabs and segmented controls

Direction:

- Compact.
- Clear active state.
- Low noise.
- Aligned with content hierarchy.

## Dropdowns and sheets

Direction:

- Clean grouping.
- Clear selected states.
- Predictable action placement.
- Mobile uses sheets where appropriate.

## Finishing rules

- Reduce excessive pill usage.
- Reduce excessive radius.
- Avoid decorative shadows.
- Make selected, active, focus, status, disabled, and loading states excellent.
