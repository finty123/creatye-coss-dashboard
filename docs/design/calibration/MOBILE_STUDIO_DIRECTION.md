# Mobile Studio Direction

Mobile Studio is a first-class product experience.

Mobile is not only for monitoring.

## Responsibilities

Mobile Studio supports:

- Edit.
- Post.
- Schedule.
- Monitor.

## Preserve successful current principles

- Large preview.
- Simple horizontal tool access.
- Contextual bottom sheets.
- Clear next step toward publishing.
- Creator-friendly interaction.
- Touch-first workflow.

## Core flows

### Quick editing

Mobile should support focused, simple editing for social content.

### Template-based creation

Templates should help users start fast without exposing Desktop-level complexity.

### Text/media adjustments

Adjustments should be direct, touch-friendly, and contextual.

### Preview

Preview is central and should remain visually dominant.

### Publish/schedule handoff

Publishing and scheduling should feel like the natural continuation of creation, not a separate admin task.

## Must avoid

- Treating Mobile as monitoring-only.
- Copying Desktop Studio panels.
- Complex timeline editing as default.
- Hiding critical actions behind gestures only.
- Redesigning the current successful interaction model without strong reason.
