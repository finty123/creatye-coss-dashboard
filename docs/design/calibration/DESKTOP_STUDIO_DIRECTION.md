# Desktop Studio Direction

Desktop Studio must feel like a creator-first social content workflow, not a heavy professional editing suite.

## Preservation rule

The current Creatye Studio journey remains conceptually valuable:

```text
SELECT -> CUSTOMIZE -> PUBLISH
```

The future direction refines this into:

```text
Edit -> Review -> Publish Setup -> Publish / Schedule
```

## Applies to

- Video Studio.
- Image Studio.

They may differ in tools, but they share journey logic.

## Target balance

Desktop Studio must balance:

- Editing capability.
- Social content simplicity.
- Publishing continuity.

## Step model

### Step 1 - Edit

Focus on creating or modifying content.

Visual priorities:

- Large preview.
- Clear selected item.
- Contextual editing tools.
- Simple creator-oriented controls.
- Lightweight sequence/timeline when useful.

### Step 2 - Review

Focus on checking final content before publishing setup.

Visual priorities:

- Preview-first layout.
- Clear errors/warnings.
- Variant/context summary.
- Direct next action.

### Step 3 - Publish Setup

Focus on selecting page, caption, schedule, target, and publishing settings.

Visual priorities:

- Integrated social publishing feel.
- Clear page/context selection.
- Premium form/panel treatment.
- Scheduling clarity.

### Step 4 - Publish / Schedule

Focus on final confirmation and operational status.

Visual priorities:

- Clear primary action.
- Success/queued/scheduled feedback.
- Next useful action.

## Must avoid

- Premiere-like editing.
- CapCut Desktop-like complexity.
- DaVinci-style professional post-production UX.
- Figma-like tool density.
- Multi-track complexity as the default.
- Export/download as the only natural endpoint.
