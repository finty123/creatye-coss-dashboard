# Calibration Surfaces

M004.5 defines four official calibration surfaces.

These surfaces de-risk the future implementation by exercising the most important visual decisions.

## 01 Desktop Command Center

Purpose: validate Home as a premium operational command center.

Must validate:

- Attention, Today, Performance, Opportunities.
- Modular premium dashboard blocks.
- Operational hierarchy.
- Non-decorative metrics.
- Action-oriented cards.

Design foundations exercised:

- Visual language.
- Cards/lists.
- Data visualization.
- Interaction states.
- Typography hierarchy.

De-risks:

- Home.
- Analytics overview.
- Operational alerts.
- Recommendations.

## 02 Desktop Automations / Operational Card-Based List

Purpose: validate card/list-first operational data UI.

Must validate:

- Automation list blocks.
- Page/status/trigger/execution/performance summary.
- Selected/active/status states.
- Action affordances.
- When tables are not the primary language.

Design foundations exercised:

- Data UI direction.
- Component taxonomy.
- Status language.
- Density.
- Control finishing.

De-risks:

- Pages.
- Automations.
- Publishing.
- Content Library.
- Activity.

## 03 Desktop Studio Flow

Purpose: validate creator-first step-based Desktop Studio.

Must validate:

- Edit -> Review -> Publish Setup -> Publish / Schedule.
- Large preview.
- Contextual panels.
- Lightweight sequence/timeline.
- Premium publishing step.
- Continuity from selection to publishing.

Design foundations exercised:

- Editor UI principles.
- Studio direction.
- Control finishing.
- Surface hierarchy.
- Publishing continuity.

De-risks:

- Video Studio.
- Image Studio.
- Templates.
- Publishing handoff.

## 04 Mobile Home / Mobile Studio Entry

Purpose: validate Mobile as real operational and creative utility.

Must validate:

- Mobile Home summary.
- Mobile Studio entry.
- Large preview.
- Bottom sheets.
- Horizontal tool access.
- Touch-first primary action.
- Publish/schedule handoff.

Design foundations exercised:

- Mobile platform design.
- Mobile UX architecture.
- Mobile Studio direction.
- System states.
- Touch patterns.

De-risks:

- Mobile Home.
- Quick Image.
- Quick Video.
- Mobile publishing.
- Activity.
