# Visual Calibration Spec

This is the official entry point for Creatye Studio Visual Design Calibration.

M004.5 formalizes the approved visual direction. It is not an open exploration, not a redesign of the product journey, and not a frontend implementation milestone.

## Purpose

Visual Design Calibration bridges:

- M002 - Design System Foundation.
- M003 - Web UX Architecture.
- M004 - Mobile WebApp UX Architecture.
- M005 - Technical Architecture.

It locks the visual direction enough for future implementation to be coherent while avoiding premature implementation values.

## Approved target

```text
CURRENT CREATYE UX FOUNDATION
+ APPROVED MODERN REFERENCES
+ NEW DESIGN SYSTEM
= REFINED CREATYE STUDIO
```

## Visual direction

Creatye Studio should feel:

- Professional.
- Modern.
- Premium.
- Creator-friendly.
- Operational.
- Clear.
- Simple.
- Intuitive.
- Fast.

It must not feel like:

- Generic AI SaaS.
- Old-school admin.
- Heavy professional editing software.
- Overdesigned crypto UI.
- Playful startup toy.
- Glassy gradient-heavy concept UI.

## Design lock

The following are directionally locked:

- Sidebar direction: clean, restrained, Linear-inspired structure and active state quality.
- Command Center direction: modular, premium, operational, inspired by Brex/Ramp quality.
- Data UI direction: card/list-first operational blocks, not dense tables as primary language.
- Desktop Studio direction: creator-first, step-based, simple and modern.
- Mobile Studio direction: first-class mobile creation experience, not only monitoring.
- Analytics direction: social/content-first, action-oriented, inspired by Dash Social qualities.
- Typography / controls direction: disciplined, precise, Vercel Geist-inspired finishing.

Future UI implementation must respect this calibration before turning M002 tokens, M003 Web UX, and M004 Mobile UX into concrete screens.
