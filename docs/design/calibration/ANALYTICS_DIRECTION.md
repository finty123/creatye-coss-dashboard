# Analytics Direction

Analytics should be social/content-first and action-oriented.

Reference quality: Dash Social.

## Visual model

Analytics combines:

- KPI.
- Trend.
- Chart.
- Top content.
- Recommendation/action.

## Purpose

Analytics should help users understand performance and act.

Examples:

- Identify content worth reproducing.
- Understand weak content.
- Review page growth.
- Inspect publishing performance.
- Spot automation issues.

## Visual priorities

- Content-oriented analytics.
- Clear metric hierarchy.
- Trend visibility.
- Top content modules.
- Action-oriented insights.
- Social/content context.

## Avoid

- Analytics that end at charts.
- Detached dashboards.
- Finance-dashboard aesthetics.
- Decorative chart density.
- Overusing tables as the default.
