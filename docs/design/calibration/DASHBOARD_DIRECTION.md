# Dashboard Direction

The Command Center should feel premium, modular, operational, and modern.

Reference quality: Brex + Ramp.

## Purpose

The Command Center helps users understand:

- What needs attention.
- What is happening today.
- How the operation is performing.
- What opportunities exist.

## Visual language

Use:

- Elegant operational cards.
- Organized modular blocks.
- Clear section hierarchy.
- Calm premium surfaces.
- Actionable summaries.
- Attention states with restraint.

Avoid:

- Promotional dashboard theater.
- Giant decorative metrics.
- Excess cards.
- Generic SaaS dashboard feel.
- Overly dense table-first modules.

## Sections

- Attention.
- Today.
- Performance.
- Opportunities.
- Recent activity where useful.

## Calibration goal

The Command Center should feel like the user is controlling a live operation, not reading a marketing report.
