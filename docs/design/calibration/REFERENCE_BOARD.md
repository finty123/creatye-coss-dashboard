# Reference Board

References define quality targets and pattern inspiration. They are not brands to copy.

## 01 Navigation / Sidebar

Reference: Linear.

Use for:

- Sidebar structure.
- Clean navigation.
- Compact hierarchy.
- Low visual noise.
- Clear active state.

Do not copy:

- Linear branding.
- Exact spacing, iconography, colors, or product-specific navigation model.

## 02 Dashboard / Command Center

Reference: Brex + Ramp.

Use for:

- Operational dashboard quality.
- Premium modern B2B product feeling.
- Clear modular sections.
- Elegant cards.
- Attention/performance/opportunities structure.

Do not copy:

- Finance-product semantics.
- Metric-heavy money dashboard patterns where they do not fit content/social operations.
- Marketing-style hero dashboard presentation.

## 03 Data UI / Collections

Direction: modern operational cards and organized list blocks.

Use for:

- Pages.
- Automations.
- Publishing.
- Content Library.
- Activity.

Do not use dense table UI as the primary visual language.

Tables may exist where comparison, bulk management, or high-density tasks materially require them.

## 04 Studio Desktop

Reference: user-approved uploaded desktop studio references and current Creatye Studio UX foundation.

Use for:

- Modern creator workflow.
- Simple editor.
- Intuitive editing.
- Preview-first layout.
- Lightweight timeline / sequence feel.
- Social content production flow.

Do not copy or introduce:

- CapCut Desktop complexity.
- Premiere complexity.
- DaVinci complexity.
- Figma-like professional editor complexity.
- Multi-track professional post-production UX.

## 05 Analytics

Reference: Dash Social.

Use for:

- Content-oriented analytics.
- KPI + trend + chart + top content.
- Social/content analysis.
- Analytics that lead to actions.

Do not copy:

- Brand identity.
- Exact layouts.
- Analytics surfaces that detach from operational actions.

## 06 Mobile

Reference: approved mobile direction based on user input.

Use for:

- Modern mobile creator/social app feel.
- Real mobile studio capability.
- Edit, post, schedule, and monitor.
- Large preview, horizontal tools, and bottom sheets.

Do not reduce Mobile to monitoring only.

## 07 Typography / Controls

Reference: Vercel Geist.

Use for:

- Typography discipline.
- Controls.
- Buttons.
- Inputs.
- Tabs.
- Dropdowns.
- Spacing and component finishing.

Do not copy:

- Vercel brand identity.
- Developer-platform visual tone where it conflicts with creator/social operations.
