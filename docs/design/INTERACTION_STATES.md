# Interaction States

States are part of the product language.

## Core states

- Default.
- Hover.
- Focus.
- Active.
- Selected.
- Disabled.
- Loading.
- Success.
- Warning.
- Error.

## Operational states

Creatye Studio also needs:

- Empty.
- Partial.
- Offline.
- Syncing.
- Processing.
- Queued.
- Scheduled.
- Failed.
- Retrying.
- Canceled.
- Published.
- Paused.
- Draft.
- Archived.

## Rules

- Focus must be visible and consistent.
- Disabled controls must explain unavailable action when the reason is not obvious.
- Loading should preserve layout stability where possible.
- Error states must identify the issue and next available action.
- Empty states should help the user continue without becoming marketing illustrations.
- Processing and queued states must distinguish between waiting, running, and failed work.
