# Accessibility

Accessibility is part of the design foundation.

## Minimum standards

- Text and interface contrast must meet appropriate accessibility thresholds.
- Focus indicators must be visible for keyboard users.
- Keyboard navigation must be considered for menus, tables, editors, dialogs, and command surfaces.
- Touch targets must be large enough for mobile use.
- Icon-only actions require accessible labels.
- Form fields require visible or programmatic labels.
- Error messages must be specific and associated with the relevant field or object.
- Disabled states must remain readable.
- Status must not rely on color alone.
- Motion must respect reduced-motion preferences.

## Complex interfaces

Tables, editors, flow builders, media libraries, and analytics must include:

- Clear focus order.
- Announced selection state where applicable.
- Non-color status indicators.
- Keyboard alternatives for pointer-heavy actions when feasible.
- Visible affordances for drag/drop alternatives in future UX work.
