# Platform Design

## Shared

Desktop Web and Mobile WebApp share:

- Brand language.
- Core tokens.
- Typography principles.
- Color semantics.
- Iconography.
- Status language.
- Accessibility standards.
- Product terminology.

## Desktop-specific

Desktop Web prioritizes:

- Standard and compact density.
- Sidebars.
- Tables.
- Editors.
- Inspectors.
- Multi-panel UI.
- Split views.
- Bulk operations.
- Detailed analytics.
- Management interfaces.

Desktop must remain usable in narrower desktop windows, including approximately half of an ultrawide monitor.

## Mobile-specific

Mobile WebApp prioritizes:

- Touch targets.
- Safe areas.
- Focused tasks.
- Reduced density.
- Quick actions.
- Approval flows.
- Bottom-navigation-compatible structure.
- Sheet patterns.
- One-handed use considerations.
- Summarized analytics and status.

## Rule

Mobile is not shrunk desktop.

M003 will define Web UX Architecture. M004 will define Mobile UX Architecture.
