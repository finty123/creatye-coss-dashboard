# Design Principles

## 1. Operational Clarity

The interface should help users understand what is happening, what needs attention, and what action is available.

## 2. Precision Over Decoration

Visual polish should come from structure, spacing, alignment, typography, and states, not from decorative effects.

## 3. Density With Legibility

Creatye Studio must support dense work without becoming cramped. Premium does not mean empty.

## 4. Shared Foundations, Distinct Platforms

Desktop Web and Mobile WebApp share language, tokens, typography principles, colors, and status semantics, but can differ in layout, density, navigation, and components.

## 5. State Is Part of Design

Loading, queued, scheduled, processing, syncing, failed, empty, partial, offline, selected, and disabled states must be designed as first-class product realities.

## 6. AI Is Controlled Assistance

AI should communicate what it is doing, what changed, how confident it is, and how the user can accept, reject, or undo changes.

## 7. Accessibility Is Foundational

Contrast, focus, labels, keyboard access, touch targets, reduced motion, and semantic status are not follow-up tasks.

## 8. Components Serve Workflows

Do not create components because they look interesting. Create or extend them only when a real workflow needs them.
