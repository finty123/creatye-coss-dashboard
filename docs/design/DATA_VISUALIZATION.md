# Data Visualization

Analytics should support operational decisions, not promotional dashboard theater.

## Principles

- Prioritize actionable comparison over decorative metrics.
- Use chart type based on question, not visual novelty.
- Avoid giant numbers unless a number is genuinely the primary decision.
- Keep legends, axes, labels, and tooltips readable.
- Separate raw platform metrics, normalized metrics, product analytics, automation analytics, content performance, and operational analytics.

## Chart and metric rules

- Trends show change over time.
- Comparisons show difference between targets, content, pages, automations, or time periods.
- Distribution views show spread or composition.
- Status views show current operational state.
- Tooltips should clarify meaning and source.

## Color rules

- Use semantic positive/negative only where direction is meaningful.
- Do not use red/green alone.
- Keep categorical palettes stable.
- Reserve saturation for attention and decision points.

## Dense analytics

Desktop analytics may use compact density, sticky context, filters, sortable tables, and drill-down patterns.

Mobile analytics should summarize signals, highlight anomalies, and provide quick actions.
