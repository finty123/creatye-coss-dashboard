# Page Archetypes

## List / Management

- Purpose: manage collections.
- Structure: header, filters/search, table/list, selection actions, status feedback.
- Primary task: find, compare, act on multiple objects.
- Typical actions: create, filter, sort, select, bulk action, open detail.
- Density: Standard or Compact.
- Context behavior: preserve filters and selection where useful.

## Detail

- Purpose: inspect and act on one object.
- Structure: contextual header, tabs/sections, primary content, optional side panel.
- Primary task: understand object state and perform relevant actions.
- Typical actions: edit, publish, analyze, configure, open related work.
- Density: Standard.
- Context behavior: carry object context into related operations.

## Dashboard

- Purpose: summarize operational state and expose decisions.
- Structure: attention, status, performance, opportunities, recent activity.
- Primary task: decide what needs action.
- Typical actions: open issue, analyze, retry, create variation, optimize.
- Density: Standard with compact data modules where needed.
- Context behavior: dashboard items link into the relevant object/action.

## Editor

- Purpose: create or modify complex work.
- Structure: top context/actions, left sources/tools, center canvas/work area, right inspector, optional bottom timeline.
- Primary task: manipulate and validate work.
- Typical actions: save, test, preview, publish/schedule, create variant, undo/redo.
- Density: Compact or Standard.
- Context behavior: preserve source object, page, content, automation, or publication context.

## Library

- Purpose: browse and manage reusable material.
- Structure: search/filter, content views, grid/list, preview, metadata.
- Primary task: find, reuse, organize, or create from assets/content.
- Typical actions: open, select, create variant, publish, schedule, use as template.
- Density: Standard or Compact.
- Context behavior: can feed Studios, Publishing, Templates, and Analytics.

## Calendar

- Purpose: view scheduled publishing over time.
- Structure: date controls, filters, calendar grid/list alternative, status markers.
- Primary task: understand upcoming and historical publishing activity.
- Typical actions: schedule, reschedule, open, retry, cancel.
- Density: Standard.
- Context behavior: respects page/platform/status/date filters.

## Settings

- Purpose: configure workspace and operational preferences.
- Structure: settings navigation, forms, status, validation, save/cancel.
- Primary task: configure durable operational behavior.
- Typical actions: update, connect, disconnect, invite, validate.
- Density: Standard.
- Context behavior: settings affect global or domain-specific behavior.

## Full-Canvas

- Purpose: maximize main work area for visual/spatial manipulation.
- Structure: persistent top context, canvas-first layout, collapsible side panels.
- Primary task: build, edit, inspect, test.
- Typical actions: zoom, select, drag/drop, test, publish/activate, save.
- Density: Compact around controls; canvas gets priority.
- Context behavior: preserve current object and selected item.

## Inspector-Based

- Purpose: edit selected object properties.
- Structure: main area plus right inspector.
- Primary task: inspect and change selected item.
- Typical actions: update property, reset, validate, apply, undo.
- Density: Compact or Standard.
- Context behavior: selection drives inspector content.
