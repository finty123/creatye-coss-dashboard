# Screen Inventory

Initial conceptual inventory:

1. Login.
2. Home / Command Center.
3. Pages.
4. Page Detail.
5. Content Library.
6. Video Studio.
7. Image Studio.
8. Templates.
9. Automations.
10. Automation Detail / Flow Builder.
11. Automation Activity.
12. Publishing.
13. Analytics.
14. Notifications.
15. Settings.

## Rules

- Tabs do not become screens automatically.
- Modals do not become screens automatically.
- Overlays do not become screens automatically.
- States do not become screens automatically.
- Calendar and List are Publishing views, not separate products.
- Queue is a Publishing operational state, not a standalone area.
- Published is a status/filter, not a separate area.
- AI is transversal, not a required primary screen.

## Inventory purpose

This inventory helps future UX and implementation work estimate surface area without expanding primary navigation.
