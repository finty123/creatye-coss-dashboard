# Core Workflows

## Connect Page

Start: workspace needs an external social destination.

1. Open Pages.
2. Start connection or page discovery flow.
3. Connect or refresh external account.
4. Select pages.
5. Confirm page availability.

End: selected pages are available for Content, Publishing, Automations, and Analytics.

## Create Content

Start: user needs publishable material.

1. Open Content.
2. Choose Library, Video Studio, Image Studio, or Template.
3. Create or reuse material.
4. Save to Library.
5. Publish, Schedule, or Create Variant.

End: content becomes operational material for publishing and optimization.

## Create Automation

Start: user needs operational behavior.

1. Open Automations or enter from Page context.
2. Create Automation.
3. Define trigger.
4. Build Flow.
5. Test.
6. Activate.

End: automation is active or ready.

## Publish / Schedule

Start: content is ready.

1. Open Publishing or publish from Content/Studio.
2. Select content.
3. Select pages/targets.
4. Choose now or schedule.
5. Confirm publication status.

End: publication is Draft, Scheduled, Publishing, Published, Failed, or Canceled.

## Analyze and Act

Start: analytics shows a signal.

1. Open Analytics.
2. Identify performance, anomaly, or opportunity.
3. Open related object.
4. Create variation, optimize, retry, correct, or open flow.

End: insight becomes operational action.
