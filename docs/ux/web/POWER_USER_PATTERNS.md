# Power User Patterns

Power-user patterns accelerate work without becoming the only way to complete tasks.

## Keyboard shortcuts

Future shortcuts may support:

- Search / Command.
- Save.
- Undo / redo.
- Open create menu.
- Quick navigation.
- Editor selection and zoom.

M003 does not define a full shortcut map.

## Command palette

Command palette can support:

- Finding objects.
- Jumping to areas.
- Creating common work.
- Running context-aware actions.

## Quick navigation

Quick navigation should support moving between:

- Pages.
- Content.
- Projects.
- Automations.
- Publications.
- Templates.

## Multi-select

Multi-select supports:

- Tables.
- Media libraries.
- Publishing lists.
- Page management.
- Automation management.

## Undo / redo

Undo / redo should be core for:

- Editors.
- Flow Builder.
- AI-applied changes where feasible.
- Bulk actions when appropriate.

## Context actions

Context actions should appear near selected objects or command surfaces, but should not hide critical options behind hover-only UI.

## Quick create

Quick create supports:

- Video.
- Image.
- Automation.
- Publication.
- Template.
