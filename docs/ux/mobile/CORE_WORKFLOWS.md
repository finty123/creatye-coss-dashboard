# Mobile Core Workflows

## Quick content

```text
Create
-> Quick Image / Video
-> Preview
-> Publish / Schedule
```

## Content reuse

```text
Content
-> Duplicate / Template
-> Edit
-> Publish
```

## Failure

```text
Activity
-> Failed Publication
-> Diagnose
-> Retry
```

## Page context

```text
Select Page A
-> Home
-> Content
-> Publish
```

All remain scoped to Page A.

## Automation failure

```text
Activity
-> Automation Error
-> Automation Detail
-> Inspect
-> Quick corrective action if supported
```

## Insight

```text
Home / Analytics Summary
-> Content
-> Create Variation
-> Publish
```

## Flow rules

- Preserve Page context.
- Prefer focused sequential flows.
- Keep primary action clear.
- Avoid forcing users into Desktop-level configuration.
