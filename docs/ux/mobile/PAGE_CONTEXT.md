# Mobile Page Context

Pages primarily function as context on Mobile.

## Context selector

Top conceptual model:

```text
Workspace
All Pages v
```

Choices:

- All Pages.
- Page A.
- Page B.
- Page C.
- Manage Pages.

## Context preservation

When Page A is selected:

- Home reflects Page A.
- Content reflects Page A where relevant.
- Publish reflects Page A.
- Activity reflects Page A.

Preserve Page context during journeys.

## Page Detail

Mobile Page Detail may include:

- Overview.
- Content.
- Publishing.
- Automations.
- Performance.

Use mobile-native patterns:

- Horizontal tabs.
- Segmented controls.
- Lists.
- Sheets.

Do not use nested sidebars.

## Manage Pages

Manage Pages may provide simplified page status and selection behavior.

Advanced page configuration remains Desktop-first unless explicitly needed on Mobile.
