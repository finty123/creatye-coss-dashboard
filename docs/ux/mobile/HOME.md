# Mobile Home

Mobile Home is an operational command summary, not a full Desktop dashboard.

## Structure

- Attention.
- Today.
- Performance.
- Opportunities.

## Priorities

Home prioritizes:

- Failures.
- Expired connections.
- Scheduled activity.
- Automation health.
- Important performance.
- Recommendations.

## Behavior

Home should answer:

- What needs attention now?
- What is scheduled or running?
- What needs quick correction?
- What opportunity should I act on?

## Avoid

- Reproducing the full Desktop dashboard.
- Giant decorative metrics.
- Too many cards.
- Dense analytics exploration.

Home should route into Content, Publish, Activity, Page context, or Analytics Summary only when action is useful.
