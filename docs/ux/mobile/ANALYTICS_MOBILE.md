# Mobile Analytics

Analytics is contextual on Mobile.

It appears in:

- Home.
- Page.
- Content.
- Automation.
- Publishing.

Analytics Summary can exist through drill-down.

Do not make Analytics a mandatory permanent bottom navigation area.

## Mobile analytics priorities

Mobile prioritizes:

- Summary.
- Trend.
- Alert.
- Comparison.
- Action.

Mobile does not prioritize complex analytical exploration.

## Action paths

Analytics should route to action:

- Strong content -> Create Variation.
- Weak content -> Analyze / Optimize.
- Publishing issue -> Retry or Correct.
- Automation issue -> Automation Detail.
- Page performance signal -> Page Detail.
