# Mobile Activity

Activity is the operational monitoring center.

It does not replace Notifications.

## Event types

Activity includes:

- Publishing events.
- Automation events.
- Render/processing events.
- Failures.
- System warnings.
- Completed jobs.

## Structure

Conceptual sections:

- Needs Attention.
- Processing.
- Completed.

## Purpose

Activity helps users:

- Monitor what is happening.
- Inspect failures.
- Track processing.
- Open completed jobs.
- Take quick corrective action.

## Relationship to Notifications

Notifications surface important alerts.

Activity provides an operational stream and history.
