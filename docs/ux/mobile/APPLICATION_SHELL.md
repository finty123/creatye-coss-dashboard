# Mobile Application Shell

## Shell regions

The Mobile shell is composed of:

- Top context bar.
- Workspace / Page context.
- Notifications.
- Main content.
- Bottom Navigation.
- Optional sticky primary action.
- Bottom Sheets.
- Full-screen focused tasks.

## Avoid

- Desktop sidebar.
- Complex top navigation.
- Multiple toolbars.
- Multi-panel desktop editor patterns.

## Top context bar

The top context bar should expose:

- Current workspace.
- Current page context where relevant.
- Notifications entry.
- Profile/account entry when appropriate.

## Main content

Main content should focus on one primary task or one clear operational summary.

## Bottom sheets

Use bottom sheets for:

- Filters.
- Selection actions.
- Contextual actions.
- Lightweight forms.
- Secondary options.

## Full-screen focused tasks

Use full-screen focused tasks for:

- Quick Image.
- Quick Video.
- Publication editing when needed.
- Focused approval/correction flows.

## Sticky primary action

Sticky primary action is appropriate when one action clearly dominates the current task, such as Publish, Schedule, Save, Retry, or Approve.
