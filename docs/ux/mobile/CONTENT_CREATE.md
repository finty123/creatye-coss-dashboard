# Mobile Content and Create

## Content

Mobile Content prioritizes:

- Library.
- Drafts.
- Recent.
- Templates.

Primary actions:

- View.
- Approve.
- Duplicate.
- Use template.
- Publish.
- Schedule.
- Share where appropriate.

Avoid exposing conceptual complexity such as Asset, Variant, Output, and Project unless necessary for the user's task.

## Create

Create is the global central action.

It opens a conceptual Action Sheet:

- Create Post.
- Create Image.
- Quick Video.
- Use Template.
- Upload Media.

AI generation may appear contextually in future flows.

Create must not become a complex submenu.

## Quick Video

Mobile Video does not reproduce Desktop Video Studio.

Conceptual support:

- Select/upload media.
- Template.
- Text/caption.
- Basic crop.
- Basic duration.
- Audio/music.
- Preview.
- Save.
- Publish.
- Schedule.

Not a primary Mobile requirement:

- Complex timeline.
- Multi-panel editor.
- Advanced professional editing.

Advanced editing remains Desktop-first.

## Quick Image

Mobile Image supports a simple flow:

1. Choose template or blank.
2. Add image.
3. Add text.
4. Crop.
5. Basic positioning.
6. AI assistance when appropriate.
7. Preview.
8. Save.
9. Publish or Schedule.

Do not reproduce Desktop Image Studio in full.
