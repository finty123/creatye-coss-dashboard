# Mobile Publishing

Mobile Publishing prioritizes operational agenda.

## Views

Conceptual views:

- Today.
- Upcoming.
- Published.
- Failed.

Supported calendar styles:

- Agenda.
- Day.
- Compact week.

Do not prioritize a complex monthly calendar.

## Actions

Mobile Publishing actions:

- Create publication.
- Edit scheduled.
- Reschedule.
- Cancel.
- Retry.
- Open published content.

## Statuses

Publishing statuses:

- Draft.
- Scheduled.
- Publishing.
- Published.
- Failed.
- Canceled.

## Mobile-friendly behavior

- Keep current Page context visible.
- Make failure/retry paths obvious.
- Use lists and agenda patterns before dense calendar grids.
- Prefer focused edit flows over desktop-like multi-panel scheduling.
