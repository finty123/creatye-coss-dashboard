# Mobile Navigation

## Bottom navigation

Approved bottom navigation:

```text
Home
Content
Create
Publish
Activity
```

Create is the central action.

## Do not add automatically

Do not add these as permanent bottom navigation items by default:

- Pages.
- Automations.
- Analytics.
- Settings.
- AI.

These capabilities enter contextually.

## Navigation role

Bottom navigation should support quick operational switching:

- Home: command summary.
- Content: library, drafts, recent work, templates.
- Create: central action sheet.
- Publish: agenda and publishing operations.
- Activity: operational monitoring.

## Page context entry

Pages primarily function as context through the top context bar:

```text
Workspace
All Pages v
```

Available context choices:

- All Pages.
- Page A.
- Page B.
- Page C.
- Manage Pages.

When a Page is selected, Home, Content, Publish, and Activity reflect that Page context.
