# Mobile Automation

Automations do not have a permanent bottom navigation item.

## Mobile automation capabilities

Mobile may allow:

- List/view automations.
- Status review.
- Activate/deactivate when permitted.
- Health review.
- Executions.
- Recent activity.
- Analytics summary.
- Inspect errors.

## Flow editing

Full Flow editing remains Desktop-first.

A simplified Flow visualization may exist.

Complex structural editing is not a Mobile requirement.

## Corrective actions

Mobile can support quick corrective actions when safe:

- Pause.
- Resume.
- Retry.
- Inspect failed step.
- Open details.

High-impact structural changes should route to Desktop or focused future flows.
